## 1. 页面状态机(修正版)

```
material_select(只列两段 Pilot 材料)
   │
   ▼
intro ──────────────────────────── 说明:本训练测"连续跟住";第一遍不可暂停/拖动
   │
   ▼
option_preview ─────────────────── 显示 3 道 check 的英文选项(不含答案)
   │                                轻量交互:每组选项选 1 个 focus chip
   │                                (人物 / 动作行为 / 原因 / 态度 / 时间地点)
   │                                可整体跳过;【只记行为,不产出任何评分】
   ▼
first_pass ─────────────────────── material 区间连续播放,无 pause/seek/replay 控件
   │                                四态: started / completed / interrupted / valid(见 §2)
   ▼
check_round_1 ──────────────────── 3 道 continuous comprehension checks(单选,一次性提交)
   │
   ▼
blind_full_replay ──────────────── 【盲重播】只显示"首次抓住:X/3",
   │                                不显示正确答案/哪题错/transcript/解析/定位;
   │                                material 完整重播一遍(仍无定位控件)
   ▼
check_round_2(recovery)─────────── 仅 round 1 答错的 check 重出(选项顺序由服务端打乱)
   │
   ▼
result_final ───────────────────── 只显示:"首次抓住:X/3;完整重听后恢复:Y/Z"
   │                                + 本次观察(observation 措辞,见 §5)
   ▼
done ───────────────────────────── 提示"逐句定位训练将在后续阶段开放"(不做链接)
```

**本阶段不出现**:正确答案、transcript、解析、答案区间、逐句定位。

## 2. First Pass 四态与中断语义(修正 §2)

- `started`:进入 first_pass 即持久化 `cp_pass_start` 事件。
- `valid`(完成判定):**不能靠单个 play 事件**。要求:播放器到达区间终点(currentTime ≥ material_end−2s 或区间 ended)**且**播放期间有心跳事件连续覆盖(每 ≤8s 一条 `cp_pass_progress`,位置单调前进)。满足才置 `first_pass_valid=true`。
- `completed`:有效完成的 pass;只有 valid pass 才产生 evidence,round 1 作答才与"首次理解"绑定。
- `interrupted`:started 但未达到 valid(中途退出/刷新/中断)。**被中断的 pass 不产生任何 evidence;允许重开 first pass**(恢复到 first_pass 阶段重新完整播放,中断事实记入事件流)。
- 一旦某次 pass valid,**不存在任何路径让学生"重新第一次听"**;恢复到 check_round_1 或其后阶段。

## 3. Blind Full Replay 与 Second Pass 语义(修正 §3/§4)

- Round 1 提交后到 Second Pass 之间是 **Blind Full Replay**:UI 只显示"首次抓住:X/3"的数量,**不揭示正确答案、不揭示哪几道错、不给 transcript/解析/定位**。
- Recovery(round 2)答对只记 `recovered_after_full_replay=true`。**不得**表述为"第二遍理解率",不得据此推断 processing speed / attention / working memory。
- result_final 显示格式固定为:"首次抓住:X/3;完整重听后恢复:Y/Z"(Z = round 1 错题数)。

## 4. Option Preview 只记行为(修正 §5)

- 记录:`preview_used` / `preview_duration_ms` / `selected_focus_types`(每组选项的 chip 选择)/ `preview_skipped`。
- **不产出** accuracy / skill 评分,**不进** Profile,不影响任何后续判分。
- 不给"标准答案";chip 选择无对错反馈。

## 5. 数据 schema(SQLite 新增三张表)

```sql
CREATE TABLE IF NOT EXISTS cp_sessions (
  id TEXT PRIMARY KEY,
  student_id TEXT NOT NULL,
  material_id TEXT NOT NULL,        -- cet6_202606_set1_u1 / set2_u1
  stage TEXT NOT NULL,              -- 状态机当前位置
  content_manifest TEXT NOT NULL,   -- 创建时 pin: {check_id: {revision, content_hash_full}}
  preview_state TEXT DEFAULT '{}',
  first_pass_valid INTEGER DEFAULT 0,
  pass_attempt_count INTEGER DEFAULT 0,  -- first pass 重开次数(含 interrupted)
  replay_count INTEGER DEFAULT 0,        -- blind full replay 完成次数
  round2_order TEXT DEFAULT '{}',        -- {check_id: [打乱后的 label 顺序]}
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS cp_responses (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  check_id TEXT NOT NULL,
  content_revision INTEGER NOT NULL,  -- 与 session manifest pin 值一致
  content_hash TEXT NOT NULL,         -- content_hash_full
  round INTEGER NOT NULL,             -- 1=first pass 后, 2=blind replay 后
  selected TEXT,                      -- 学生看到的 label(已映射回原始 label)
  is_correct INTEGER,
  recovered_after_full_replay INTEGER DEFAULT 0,  -- 仅 round=2 且答对
  answered_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS cp_events (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  student_id TEXT NOT NULL,
  event_type TEXT NOT NULL,   -- cp_preview_open / cp_preview_mark / cp_preview_skip /
                              -- cp_pass_start / cp_pass_progress / cp_pass_end /
                              -- cp_pass_interrupted / cp_replay_start / cp_replay_progress /
                              -- cp_replay_end / cp_round1_submit / cp_round2_submit / cp_session_summary
  payload TEXT DEFAULT '{}',
  client_at TEXT,
  server_at TEXT NOT NULL
);
```

**内容版本绑定(修正 §6)**:session 创建时把 6 道(该材料 3 道)check 的 `revision + content_hash_full` pin 进 `content_manifest`;每条 cp_response 冗余存储 pin 值。服务端在提交响应时校验:当前内容文件的 hash 若与 pin 不一致(教师改了内容),该 session 仍按 pin 值判分与记录——旧记录可还原当时版本;服务端在响应中标注 `content_drifted=true` 但不改判分基准。

## 6. Evidence schema(只产生 observation)

session 进入 result_final 时聚合写一条 `cp_session_summary` 事件:

```json
{
  "material_id": "cet6_202606_set1_u1",
  "first_pass_score": "2/3",
  "recovered": "1/1",
  "checks": [
    {"check_id": "cp_cet6_202606_set1_u1_01", "dimension": "speaker_relationship",
     "round1_correct": true, "recovered_after_full_replay": null}
  ],
  "observations": ["continuous_speaker_tracking_correct", "continuous_change_tracking_failed"],
  "profile_eligible": false
}
```

observation 封闭词表(dimension → 词根):
`speaker_relationship→continuous_speaker_tracking_*`、`change_tracking_attitude→continuous_change_tracking_*`、`conditional_scope→continuous_condition_scope_*`、`main_situation→continuous_main_situation_*`、`initial_vs_final_decision→continuous_final_decision_*`、`attitude_target_speaker_swap→continuous_attitude_target_*`,后缀 `correct/failed`(按 round 1 判定)。
**禁止**输出 attention / working_memory / processing_speed 类 hypothesis;**不进** Profile(`profile_eligible=false`)。

## 7. 内容文件与安全

- 内容:`data/v2_practice/cp_items.candidate.json`,每题带 `check_id / revision / content_hash_blind / content_hash_full / target_dimension / question / options / claimed_answer / supporting_segments / content_status=generated_unverified`。
- 学生端 bundle 白名单:`material_id / audio{url} / material_start_ms / material_end_ms / checks[{check_id, target_dimension, question, options[{label,text}]}]`。**禁止**出现 claimed_answer、hash、supporting_segments、transcript、provenance 等;组装后跑递归禁止字段断言(复用 v2_exam_service.assert_no_forbidden,并追加 cp 专用禁词)。
- 音频:复用整套音频文件,前端按 [material_start_ms, material_end_ms] 区间播放并强制钳制;工程 Pilot 阶段接受前端钳制(student_release_allowed=false,不对外)。
- release gate:与 V2.1 Exam 完全共用(`student_release_allowed()` + `ALLOW_UNRELEASED_LISTENING_V2` 开发预览开关)。
