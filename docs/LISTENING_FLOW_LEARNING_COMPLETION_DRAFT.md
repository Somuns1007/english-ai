## 4 学生首页与模式应如何分工

建议首页面向学生显示三个主要行动，其余收进次级导航：

1. **继续上次学习**：优先显示确实未结束的、属于自己的学习会话。
2. **完成一段听力**：区分连续理解 Pilot 与整套考试；选择依据是时间和用途，不是先做诊断。
3. **复习今天的声音卡**：只显示自己的到期卡，不预先推送尚未听过的试卷词表。

“能力画像”不作为所有学习的起点。未做过任何题的学生先选目的和可用时间；不要求先背40词才能听第一段。若选择预习辅助，明确标记辅助，不取消学习资格。

### 4.1 保持 Exam 独立

正式 V2 考试保持英文 A/B/C/D、audio_only 问题、同 Unit 3—4题同时可见，不加自动题号定位、词汇弹窗或实时解析。不把逐句训练混入考试播放器。

交卷后可保留已有分数，再提供“学习这套材料／稍后再学”。考试交卷后已看成绩的重听，属于考后学习；不能套用 CP 的 blind recovery 指标，更不能伪装成重新独立首听。

本次不提议强制考试后把整套再播两遍。学生可选一个 Unit 学习，也可以结束当天任务。

### 4.2 保持冻结 CP 状态机

intro → 可选 option_preview → first_pass → check_round_1 → blind_full_replay → check_round_2 → result_final。

现有终态分支以服务端状态为准；首次全对等分支不因本文插入新要求。第一遍与盲重播期间不增加回想框、词汇预教或停顿，也不显示答案位置。recovery 保持原有语义，不更名为第二遍理解率或能力改善。

新学习会话在 `result_final` 之后另建，不把新阶段塞进 `v2_practice_service.py` 或修改旧 session 的历史内容。当前 Set2 U1 先试点，其他6个单元必须先有经核验边界和独立任务定义。

### 4.3 学习模式不强制完整测验

未来可提供直接学习入口：先声明“本次为辅助学习，不作为独立测评”，记录所发生的曝光，然后按需使用文本。不要求学生为了学习一段材料先交25道空白答案。

直接学习也必须受 release、版权、封存和身份条件约束。完成状态不是版权许可，选择辅助模式也不能打开封存 Set1。

## 5 后置学习会话的具体流程

```text
已授权的考试交卷／CP终态／明确的辅助学习入口
  → 创建学习会话与内容版本快照
  → 可选主线回想
  → 自主选择困难位置
       ├─ 找不到：整段重听或按原顺序逐句探索
       ├─ 整体太难：辅助理解或结束，建议后续更易的新输入
       └─ 有困难句：先听并尝试 → 主动揭示 → 选择一种短练习
  → 撤去文字再听或复述（可选）
  → 选少量声音卡／跟读／新情境表达（三者不必全做）
  → 保存并结束 → 下次继续／到期复习
```

### 5.1 主线回想

页面文案：“不用记住原句，用一句中文或简短英文说说这段主要讲什么。也可以跳过。”

默认是自我回想，不由关键词命中率自动判成理解成功。允许记录“未作答”，不填0分，不生成人格或认知结论。具体单元问题和参考要放在完成盲听后，不能提前用题目提示主旨。

### 5.2 自主定位

学生可标记当前播放位置，或打开无文字的顺序句子目录。默认不高亮答案证据句，不从错题自动跳到某句。定位失败并不应再强迫学生猜位置；可以提供更宽的全段上下文或允许按顺序学习。

在任何词条、难句推荐、搜索结果和 URL 直达路径上都应用同样规则：句子重要不等于学生可以被提前告知它就是答案位置。

### 5.3 先尝试后揭示

同一句提供三种尝试方式：说意思、写听到的一部分、标记“暂时没听出”。学生选择其一，不必全做。

揭示按钮顺序：英文 → 本句中文解释 → 可选结构说明。允许学生主动提前揭示，但记录辅助使用，停止对这次尝试赋予独立性。不是通过强制点完按钮制造合规假象。

解析选项和“第几题答案对应这里”放在另外的题目解析权限中；句子解释不自动带出 A/B/C/D。全文文字一旦可见，相关题目的后续表现就是 text_exposed，隐藏页面不能恢复独立性。

### 5.4 每次只推荐一种短练习

| 学生报告的本次困难 | 建议练习 | 完成方式 | 不应做的推断 |
|---|---|---|---|
| 看文字也不知道意思 | 本句词义＋一个新情境例子 | 能说本句大意；是否收藏由学生决定 | 不诊断总体词汇量不足 |
| 文字认识，声音没认出 | 原句声音→对照文字→撤字重听 | 学生记录是否认出；有答案任务才保存对应结果 | 不仅凭选择该标签断言连读障碍 |
| 词听到了，关系没连起来 | 条件／转折／主体指代复述 | 说清本句关系，允许中文 | 不推断工作记忆或处理速度 |
| 主要是拼写困难 | 短词组听写，对齐差异反馈 | 看漏词、拼写和词尾，允许重试 | 不把写错等同没听懂意思 |
| 已理解，想学表达 | 跟读后用自己的情境说一句 | 自我回放或文本产出，不要求与参考逐字一样 | 不把表达完成写成听力能力提高 |
| 材料整体过难／疲惫 | 后置文本辅助、缩短任务或结束 | 保存暂停点，允许不完成任何卡片 | 不自动安排全文每句听写 |

建议时间预算为可调整试点参数，不是科学门槛：一次后置学习先提供约5—10分钟选项，默认1—3个困难点；愿意深入者可以继续。全对但猜中、不确定或想学习表达的人同样能进入，不要求先有错题。

### 5.5 撤字复听与退出

页面文案：“现在把文字收起来，再听听这句话。你不需要背出每个词。”结果写“本次撤字后能复述／仍需复习／跳过”。因为之前见过文字，不能叫无辅助的首次成功。

退出时只显示三项事实：本次处理了哪些内容、选了哪些卡、下次可继续哪一步。学生可以不收藏、不录音，仍正常结束会话。

## 6 生词和俚语的提前学习政策

推荐默认：本材料首听前不展示从材料提取的词表、表达解释、新编同义例句或主旨摘要。Word 式“选项语境义”和“注意事项”尤其不能当预习资料直接送出。

可以提供独立基础词汇学习，但若学生曾学过与目标材料相关的定向词卡，应记录关联曝光，不能声称该材料完全没有预教。一般英语词汇知识本身不是作弊；重点是本系统是否按目标材料提前提供了线索。

允许学生选择“先预习再学”：明确为 scaffolded 学习，不计未辅助首听；不得因此绕过 Set1 封存或商业内容权限。不把 Phase 0 的70%、21天等旧启发式解释成学习科学定律。是否调整现有 Phase 0 产品策略另需确认，不在本次改代码。

把词条分成单词、搭配、固定表达、句子结构和专业名词；不全称俚语。页面允许展开音标、词族等有用信息，不强制所有条目填反义词。实际录音中的音变必须听核后标注，不能从书面拼写直接宣布“这里吞了某音”。

## 7 词汇 SRS 与表达迁移的接入

### 7.1 不创建第二套独立词库

复用已有 lex_items 与调度能力，但需要审核目标义项与来源：

- `surface` 相同不代表意义相同，如本文不同语境的 work、fit、composition；可共享词头，但不能覆盖义项。
- 同一义项多次出现在材料中，可挂多个 occurrence；SRS 不重复刷同义卡，但曝光来源不能丢。
- 每张卡分别记录 sound→meaning、sound→spelling、meaning→production 任务，不能用看英文选中文的一次通过代替声音识别。
- 错词不无限入队；积压时优先复习旧卡、暂停新增，允许学生删除或搁置卡片。
- 暂无音频时可做文字学习，明确标注；不伪造 aural recognized 事件。

### 7.2 先试点原音，后接合成音

首版使用经审核的原句片段做声文对照和复习。新编例句需要新音频才能做真正的声音练习；没有音频时只标为文字输出任务。以后 TTS 生成要标注 synthetic，并记录审核状态，不伪装成考试录音或独立真人语料。

### 7.3 跟读到表达迁移

顺序为理解→短句跟读→录音自我比较（可选）→换情境表达。第一次不做边听边说的强制影子跟读，也不自动给发音87分。

现有 Expression 模块有场景、音频与审核能力；先核查是否能接受新任务类型与学生产出，不把它误称为已经有口语评测。录音以后必须单独具备权限、删除和成本策略。

Set2 U1 的 offset 可与既有同词表达场景核对复用，但重复词义和相似情境只能作练习，不自动计独立迁移。Set1 的任何表达目前都不能进入公共场景池。

## 8 内容与会话数据契约草案

以下是拟新增学习域的概念，不是本次数据库迁移要求；必须先与既有 Evidence Foundation 设计对齐。

| 对象 | 最小字段和含义 |
|---|---|
| LearningMaterial | `material_id`、源 exam/unit、pool、release/rights/review 状态、父媒体及版本 |
| LearningSegment | `segment_id`、所属 material、源文本锚点、文字revision/hash、时间边界及独立审核状态 |
| LexicalOccurrence | 词头、义项、出现位置、源 segment、来源类型（原文／选项／教学新编）、显示权限 |
| LearningSession | owner、入口来源（exam_attempt／cp_session／assisted）、源记录 ID、版本快照、阶段、暂停点 |
| ExposureRecord | 实际播放或文本展示、时间、来源、资源版本、学生身份可靠性；与能力证据分离 |
| LearningAttempt | 任务类型、学生实际输入、帮助条件、结果、反馈版本；纯浏览不生成理解成功 |
| ReviewTask | 复习的词义或句子、输入输出方向、到期日、完成事实；不直接更新整体 Profile |

词条与句子自带 `content_hash` 不等于历史 response 已绑定：创建会话时服务端保存内容快照引用，提交时服务端绑定，不接受客户端任意 hash。源改版后旧记录仍引用原版，不能按最新答案重算历史学习结果。

### 拟新增接口边界

路径为提案，当前不存在，不应让前端直接调用：

- `POST /api/listening/learning/sessions`：验证入口记录归属、终态、内容来源和许可，创建后置会话。
- `GET /api/listening/learning/sessions/{id}`：返回当前允许的状态和无泄露目录。
- `POST /api/listening/learning/sessions/{id}/attempts`：保存本次句子尝试，不先返回目标答案。
- `POST /api/listening/learning/sessions/{id}/reveal`：记录实际文字辅助并返回当前层级允许的内容。
- `POST /api/listening/learning/sessions/{id}/finish`：幂等保存退出状态与学生自选后续任务。

词汇、表达复用既有 API 还是新增适配，由实现时兼容性测试决定；不得把整个 candidate JSON 发送给前端后靠 CSS 隐藏。鉴权失败不得降级匿名来访问用户录音、学习历史或受限内容。匿名兼容政策需要明确，不能从旧写入放行逻辑自动继承。

### 授权必须同时满足

`内容允许发布 AND 来源许可允许该用途 AND 未被封存策略阻止 AND 主体有权访问 AND 入口条件成立 AND 当前阶段允许展示该字段`。

其中任一为 false 或 unknown，敏感内容不下发。一个别人已提交的 attempt 不能用来打开自己的全文；一个已完成 U1 的 session 不能解锁 U7。完成考试也不自动允许出版物衍生全文分发。

## 9 曝光和测评的边界

- Set1 默认封存；这份学习稿本身会污染读到它的学习者，因此只交给项目负责人内部使用。
- 已存在 CP 的 Set1 U1 要按学生曝光退役；不能保证该套完整25题都是独立测评。历史不明确则记录 unknown，不记0次。
- 同材料换问题、换声音、改写例句不自动成为新的 holdout；保持父内容关系。
- Set2 的逐句学习、SRS 和表达迁移后，所有同源后续任务都属于 familiar 或 scaffolded。
- 可以检查延迟保持和同材料整合，不能证明整体听力增长。两套都熟悉后必须承认陌生材料验证暂缺，不能用“榨干”作为永不补充新输入的理由。
- CP recovery、学习完成、复习天数、播放时长不进入正式 Profile。新内容统一 `profile_eligible=false`，除非今后有独立规范和授权修改。
- 学生回想、错因选择、重试次数只作本次观察，不输出 working memory、attention 或 processing speed 推断。

## 10 面向手机和中断的必补体验

先测试浏览器允许的真实行为，不承诺网页可阻止所有系统暂停：

1. 手机来电、锁屏、切后台或音频焦点丢失时，CP 按既有中断规则记录；重开不能抹去已播放曝光。
2. 网络断开后先保留输入，明确“未同步”，服务端成功后才显示已保存；提交使用幂等键防止重复入队。
3. 切换账号清除当前用户缓存与待发事件归属，旧学习会话不能悄悄写入新账号。
4. 逐句目录不要求精确拖动小滑块；提供上一句／下一句和足够大的点击区。默认不在多个组件同时播放音频。
5. 正式考试组内3—4题保持可浏览，不能为了移动端省空间变成一题一屏自动跟随音频。
6. 录音可拒绝授权，学习仍能继续；耳机不是硬性资格，环境噪声可由学生标记。
7. 没有已审核切片则禁用精确播放并提示原因；不要反复播放空区间或将答题静音当句子。

## 11 两套材料的试点安排

不是固定课表，也不是学习收益已验证的天数。下面是给单人产品试点使用的可调整安排：

| 次序 | 学生任务 | 网站验证目标 |
|---|---|---|
| 第一次 | Set2 U1 现有 CP，完成或暂停均按原规则记录 | 首听条件不被新内容破坏，终态能正确创建学习会话 |
| 第二次 | 从 U1 选一个困难句；可选收藏1—3张卡 | 学习不是必须先确诊；内容揭示和来源绑定正确 |
| 第三次 | 到期声音复习；可选一句跟读或新情境输出 | 卡片任务方向分开、退出正常、无假能力结论 |
| 扩展 | 逐步审核并加入 Set2 U2—U7，按兴趣和困难选段 | 切片、题目与上下文不串单元；内容成本可承受 |
| 稍后 | 自愿进行 Set2 整套考试或重做 | 已曝光标签明确，成绩只代表本套熟悉条件下表现 |
| 保留 | Set1 等待治理决策和具体学生资格核查 | 不因本稿存在就被批量放进学习或词库 |

先邀请少量目标学生观察操作卡点、任务时长、疲劳、是否知道下一步。可用5—10人作为可管理的可用性试点规模，不足以证明教学有效性。记录退出理由，而不是把退出一律算学习失败。

## 12 实施优先级与工作量

以下为熟悉现有项目的单人粗估，包含基本测试，不含授权谈判、全部音频人工听核和持续教学评估。须先获实现授权，不代表本次已实施。

| 优先级 | 工作包 | 粗估 | 依赖与完成定义 |
|---|---|---|---|
| P0 | 确认两套身份、封存范围、版权与版本清单 | 工程整理1—2天；审核时长另计 | 可明确回答谁可看哪一版内容，不用词稿代替许可 |
| P0 | 新学习域身份、来源、曝光与解锁契约 | 3—5天 | 跨用户／跨材料／提前揭示均被后端拒绝；不改 CP 核心 |
| P0 | Set2 U1 后置桥接与 Sentence Lab Lite | 4—7天 | 正常退出、保存和撤字重听可用；依赖经审核句子边界 |

暂不做大型词典、所有词音标强制标注、全量影子跟读、无限 AI 出题、统一能力雷达图、正式发音评分。深度稿保留扩展空间，首个运行版本只选最小闭环。

## 13 验收案例

本节是未来实现时的测试需求；本次没有运行这些尚不存在的功能测试。

### 防泄露与隔离

1. 未交卷的 V2 attempt 请求学习 reveal → 拒绝，不返回全文、释义、来源摘要或词卡预览。
2. CP 非 result_final 请求学习内容 → 拒绝；旧 bundle 递归禁止字段测试继续通过。
3. 用户B持有用户A的已完成 gate_id → 拒绝；用户A持 U1 gate_id 访问 U7 → 拒绝。
4. 直接访问新学习 URL、词卡详情、搜索、导出、媒体地址 → 使用同一权限原则，不能靠前端隐藏。
5. Set1 内部稿不能被 seed、日常推荐或公共 AI 检索读取；已有 Set1 U1 曝光不被重置。
6. 开发预览不改变 baseline 标志，生产关闭预览时仍正确拒绝；内容 release 撤销后旧会话也不能继续取受限内容。
7. 新源版本出现时，历史 response 仍绑定旧版；客户端伪造 revision/hash 不改变绑定。

### 学习交互

8. 首答全对但不确定的学生仍能主动学习；不要求生成 diagnosis。
9. 定位失败允许整段或顺序探索；系统不会跳到答案证据区间。
10. 学生可跳过回想、听写、录音或收藏，保存并退出；不强迫七步通关。
11. 揭示英文后，任何撤字复听明确 familiar/scaffolded；不恢复独立性。
12. 漏写一个词只产生适当的对齐反馈，不把后续全句都视为声音识别错误；拼写反馈不冒充语义诊断。
13. 不同义项或来源的同词可追溯；同义复习卡不重复入队；词卡对照后成功不更新正式 Profile。
14. 手机中断、刷新、重复提交、账号切换、离线恢复均不丢失既有曝光或串账号。
15. 缺切片或内容待审时给明确状态，不播放错误位置，不假装已生成逐句训练。

### 现有回归

保留 `test_v21_exam.py`、`test_v22_practice.py` 的冻结规则；在隔离数据库中执行 auth、harvest、aural lexicon、pacing、expression、dashboard 相关测试及后端完整测试。前端执行 build 与真实手机浏览器验证。新增测试不能连接真实 listening.db；实现前后比较数据库和冻结材料哈希。不能拿旧测试全通过代替新学习契约测试。

## 14 需要用户确认的决策

这些问题不阻止本次写稿，但会阻止未经确认的上线或旧规格变更：

1. 将本工作定为独立“两套材料深化 Pilot”，还是正式修改原 V2.3 非目标？默认建议独立 Pilot。
2. Set1 继续封存，还是对已完成测评的具体学生开放？默认继续封存，不批量入库。
3. 当前候选全文与衍生释义的使用许可、teacher review 由谁完成？没有审批则仅内部预览。
4. 是否批准把强制词汇前置策略改为可选辅助学习？本稿建议可选，现有 Phase 0 不自动修改。
5. 新学习历史与未来录音是否要求登录？当前匿名兼容不能自然等同安全账户存储，须明确归属策略。

## 15 建议交给下一位开发者的第一张任务单

不要直接实现全部稿件。先实现“Set2 U1 已完成 CP → 独立学习会话 → 一句先尝试后揭示 → 正常保存退出”，并通过权限、来源、版本、曝光测试。缺少句子边界或发布许可时停在内部预览，不开启正式学生 gate。

第二张任务单才接一张声音 SRS 卡；第三张再扩学习句与单元。全部旧模块先评估适配，不做无关重构；不得把含内部稿件的 docs 目录作为静态站点目录公开托管。

这次补全的成果是可执行的稿件与验收要求，不是网站功能已经改好。最终效果应是学生能在一次短学习中解决一个具体困难，并知道下次继续什么，而不是页面增加了多少字段。
