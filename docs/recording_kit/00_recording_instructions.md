# 真人录音试点 · 录音说明（组织者 + 录音者必读）

Phase 7.7 Human Recording Pilot：3 张任务卡 × 2 个独立版本 = 6 段对话。

## 给录音者的话（请组织者开场读一遍）

1. **这不是考试，也没有台词。** 你只会拿到你自己角色的目标，对方的卡你看不到。
2. 像平时说话一样：可以犹豫（um, uh）、可以说一半改口、可以打断对方、可以让对方重复——这些恰恰是我们要的，请**不要克制**。
3. 不知道怎么说就用你自己的话说。说不"高级"完全没关系，自然比漂亮重要。
4. 目标是把事情谈完（问到该问的、说清该说的），1.5–3 分钟自然结束即可。
5. 不要故意加背景噪音，也不要故意表演情绪。

## 组织流程（组织者操作）

1. 选两位录音者（英语水平不限，自然即可；两版本尽量换人）。
2. 分别发角色卡：**A 只看 Role A 页，B 只看 Role B 页**，互相不看对方的。
3. 给 2 分钟各自默读自己的卡，**不要对词、不要排练**。
4. 手机录音（安静房间，手机放两人中间），说完按停。
5. 每段录完立刻在 `04_consent_log.md` 登记授权记录（先确认已签授权协议）。
6. 文件按 `_incoming_recordings/README.md` 的命名规范放入接收区。
7. 组织者 + 两位录音者花 5 分钟填 `05_card_evaluation.md` 的任务卡自评。

## 设备与环境

- 手机自带录音机即可；安静室内；不要播音腔、不要朗读感。
- 每段一个文件；同一张卡的两个版本要换录音者或至少隔几天重录。
