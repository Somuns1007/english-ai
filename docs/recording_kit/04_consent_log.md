# 授权登记表（Consent Log）

> 每段录音进入 ingestion 前，必须在这里有一行对应记录。

> consent_id 规则：`CONSENT-年份-序号`，同一对录音者签一份协议可覆盖多段录音；
> 每段录音一行，关联到具体 consent_id。
