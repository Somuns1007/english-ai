# 任务卡 1 · Version B：酒店满房变体（card_hotel_fully_booked 试点第二版）

> 与 01(Version A)相同的交际功能：告知无房 + 提供替代 + 确认意向。
> 但具体条件不同，**不要参考 Version A 的录法**。打印后从中间裁开，A、B 不互看。

---

## Role A —— 客人（只给你看）

你在为**下个月的周末**（不是今晚）提前订房：两晚，周五入住周日离店，两个人。

**你的处境：**
- 你预算有限，想订普通双床/大床房。
- 如果普通房没了，你可以考虑：贵一点的房型（但要问贵多少），或者**改到前一个/后一个周末**。

**你要达成的事：**
1. 问下个月那个周末还有没有普通房。
2. 如果没有，问清：还有什么房型？贵多少？换周末行不行？
3. 最后做一个决定（订 / 再想想 / 换日期），别不了了之。

**你的隐藏信息（对方不知道，合适再说）：**
- 你是去参加朋友婚礼的，日期其实是死的——"换周末"对你其实不可行，你只是拿它当讨价还价的筹码。

**记住：** 没有台词。用你自己的话。犹豫、改口、追问都可以。

---

## Role B —— 预订部（只给你看）

你在酒店预订部接电话。**客人问的那个周末：普通房（标准间）全满。**

**你掌握的信息：**
- 还剩：豪华大床房（每晚贵 40%）和套房（贵一倍）。
- 前一个周末普通房还有；后一个周末普通房也还有。
- 本周内预订豪华房可以送双早（你能给的最大让步，别主动全抛出来）。
- 你不能给普通房"排队等取消"以外的承诺。

**你要达成的事：**
1. 说清普通房没了，但**别只说"没了"**——把还剩什么讲清楚。
2. 客人犹豫时，可以提"提前/推后一个周末还有普通房"。
3. 客人如果明显嫌贵，最后可以抛出"本周订豪华房送双早"。
4. 确认结果：订哪种 / 哪天 / 留姓名电话，或礼貌结束。

**你的隐藏信息（对方不知道）：**
- 其实套房你今晚特别想卖出去（店长有指标），但别表现得太急。

**记住：** 没有台词。客人可能讨价还价、可能反复比较——像真预订员一样应对。
