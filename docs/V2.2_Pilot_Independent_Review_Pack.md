# V2.2 Pilot — Independent Review Pack(独立盲审包)

生成时间:2026-08-28
生成方:Kimi(第一方);本包供**独立审核者**(第二方模型或教师)对 V2.2 Pilot 的 6 道 Continuous Comprehension Check 做第二轮盲审。

## 使用说明(给审核者)

1. **先做 PART A，再看 PART B。** PART A 不含任何答案、评价或设计意图,请仅凭 transcript 独立作答 6 道题,并记录你自己的答案与依据 segment。
2. PART B 是第一方声称的 ground truth 与完整证据矩阵,用于你完成独立作答后逐项比对。
3. PART C 是音频边界的机器证据,请判断两段材料的 `material_start_ms/material_end_ms` 候选值是否可接受。
4. PART D 是来源局限性声明。本包中**没有任何字段经过人类审核**;所有状态均为机器/模型级。
5. 审核结论请按 field/segment 粒度给出(PASS / NEEDS_REVIEW + 理由),不要只给整段一个笼统结论。

## Hash 规范(防泄题设计)

- PART A 中的 `content_hash_blind` = SHA256( canonical JSON `{check_id, revision, question, options}` ),`sort_keys=True, separators=(',',':')`, UTF-8。**不含答案**,防止审核者用 4 次穷举反推出正确答案。
- PART B 中的 `content_hash_full` = SHA256( canonical JSON `{check_id, alias, revision, target_dimension, question, options, claimed_answer}` )。两者一一对应,审核完成后可用 PART B 的全量字段复算验证。
- 任何字段被修改 → revision +1,两个 hash 全部重算,旧审核结论作废。
